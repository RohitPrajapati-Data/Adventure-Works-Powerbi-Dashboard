# Adventure Works Power BI Dashboard

## Project Overview

This Power BI dashboard analyzes sales performance, cost analysis, order trends, product performance, and regional sales insights for Adventure Works.

## Business Requirements

- Analyze overall sales performance.
- Compare sales and cost trends.
- Track yearly growth.
- Evaluate product performance.
- Analyze regional sales distribution.
- Monitor quantity sold and order trends.
